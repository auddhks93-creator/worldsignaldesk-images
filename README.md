# World Signal Desk — public editorial photos

Public image-only hosting repository for [World Signal Desk](https://worldsignaldesk.blogspot.com/). The blog's development code and editorial notes stay in a separate **private** repository.

## Rules

- Publicly commit **only photos deliberately selected for publication**; keep original uploads private.
- Remove camera EXIF and GPS data, resize/compress to web-friendly JPEG or WebP, and check the preview before publishing.
- Do not publish photos showing identifiable companions without clearance, or banknote serial numbers and unrelated personal details.
- Preserve photographic accuracy: do not turn an altered/generative image into claimed documentary evidence.
- Use descriptive lower-case filenames and group by story/date, e.g. `travel/south-korea/incheon/bupyeong-restaurant-2026-10-21/menu-cash-prepaid.jpg`.
- Verify the **public** HTTPS file before inserting it into Blogger HTML. For a file on branch `main`, the format is:
  `https://raw.githubusercontent.com/auddhks93-creator/worldsignaldesk-images/main/<path/to/verified-file.jpg>`.
- Public repository files are visible to anyone and may be copied by third parties.
